Movie Bot Guide

How to turn the bot on from your PC, and how to use every command.

The Movie Bot looks up movies and creates the posts in your #movie-recommendations forum for you: title, IMDb and Rotten Tomatoes ratings, description, duration, poster and the status tag (To Watch, Watched or Coming Soon). It also suggests movies by genre or by similarity.

The most important thing to know: the bot only works while it is running on your PC. If the PC is off, asleep, or the bot window is closed, the commands answer "The application did not respond". Part 1 shows how to start it.

Part 1: Turn the bot on (your PC)

Start the bot

  1. Open a terminal in the bot's folder. Easiest way: open the folder D:\Documents\discord-bot in VS Code, then choose Terminal → New Terminal.
  2. Type this and press Enter: 
    npm start
  3. Wait a few seconds until you see this line (the number of commands may be higher in the future): 
    Logged in as Movie Bot#5009 with 12 commands loaded.
  4. The bot is now online. Leave that terminal window open. You can minimise it.

Turn the bot off

Click in the terminal where the bot is running and press Ctrl + C (once or twice). Closing the terminal also stops it.

Keep it running

  • Do not let the PC sleep while the bot should be online. In Windows: Settings → System → Power → set Screen and sleep to Never for "When plugged in, put my device to sleep".
  • The bot refreshes the ratings and the Coming Soon tags by itself once a day, but only while it is running.
  • Run the bot on one PC at a time. If it runs on two PCs, both answer every command and you get duplicates or errors.

After you change anything in the code

  • Restart the bot (Ctrl + C, then npm start). The bot loads its commands only when it starts. A command added while the bot is running will not answer until you restart it.
  • If a command's name or options changed, also run this once, then restart the bot: 
    npm run deploy
  • To run the automatic tests: npm test.

Setting up on another PC (for example the laptop)

  1. Install Node.js (the current LTS version or newer; the desktop uses v26). The bot needs a recent Node because it uses Node's built-in SQLite.
  2. Get the code: git pull origin main in the existing folder, or clone github.com/CodenameTempest14/movie-discord-bot.
  3. In the folder, run npm install.
  4. Create a file named .env (copy .env.example) and fill in the five values listed in Part 4. The .env file is never in git, so you must copy the values yourself.
  5. Start with npm start.
The movie list does not travel with git. The bot remembers which forum posts it created in data\bot.sqlite, and that file is not uploaded to git. A second PC starts with an empty list, so /watched would refuse posts made from the other PC. For now, use one PC as the bot's home.

Part 2: Using the bot in Discord

Type / in any channel and pick a command from Movie Bot. Options marked optional can be skipped.

Everyday commands

CommandWhat it doesWho
/addmovie title [year] [popcornmeter] Creates a post in the movie forum: title Name (Year), IMDb rating, Rotten Tomatoes %, description, duration, poster, and the tag (To Watch, or Coming Soon if the movie is not released yet). If two movies share a title, add the year. popcornmeter is the Rotten Tomatoes audience score; no website gives it to the bot, so you type it (like 76%) or leave it out. The bot will not post the same movie twice. Thesis-Member, Officer, admins
/watched Run it inside a movie post. Changes the tag to Watched. Thesis-Member, Officer, admins
/unwatched Run it inside a movie post. Moves the tag back to To Watch (or Coming Soon if not yet released). Thesis-Member, Officer, admins
/movie title [year] [popcornmeter] Shows the movie's info in the channel without creating a forum post. Good for a quick look. Everyone
/recommend genre [genre2] [min_rating] Suggests 5 popular movies in a genre. genre2 asks for movies that match both genres. min_rating (1 to 10, default 6.5) is the lowest TMDB rating allowed. Run it again for different picks. Everyone
/similar title [year] Finds the movie, then suggests 5 movies like it. Everyone
/refresh Updates ratings and flips Coming Soon posts to To Watch after release, right now. This also happens automatically once a day. Thesis-Member, Officer, admins

Genres for /recommend: Action, Adventure, Animation, Comedy, Crime, Documentary, Drama, Family, Fantasy, History, Horror, Music, Mystery, Romance, Science Fiction, Thriller, War, Western.

Tags: the forum needs three tags named To Watch, Watched and Coming Soon. Emoji, capital letters and extra spaces in the tag names are fine, and your emoji stay as they are.

Admin commands

CommandWhat it doesWho
/setup forum role1 [role2] [announce_channel] [timezone] Chooses the movie forum and which roles may use /addmovie, /watched and /unwatched (server admins always can). It then checks that the three tags exist and that the bot has its permissions, and lists anything missing.
The last two options are for the upcoming movie night feature: announce_channel is a text channel for polls and reminders, and timezone is a name like America/New_York. You can leave them out; leaving them out keeps whatever was saved before.		 Manage Server
/apiusage Shows how many of OMDb's 1,000 free daily requests the bot has used today. The bot counts them itself, because OMDb does not report this. Manage Server

Fun and test commands

CommandWhat it does
/pingChecks that the bot answers, and shows its delay.
/hello [user]Says hello.
/roll [sides]Rolls a die (6 sides unless you choose a number from 2 to 1000).

Adding your first movie, step by step

  1. Type /addmovie, fill in title (and year if needed), press Enter.
  2. Wait a moment. The bot replies with a link to the new post in #movie-recommendations.
  3. When you have watched it, open that post and type /watched. The tag changes.
  4. Changed your mind? /unwatched inside the post.

/watched and /unwatched only work in posts the bot created. Hand-made posts are refused on purpose.

Part 3: If something goes wrong

What you seeWhy and what to do
"The application did not respond" The bot is not running, or was started before the command existed. Start it with npm start, or restart it. Also check that the PC did not go to sleep. A slow internet connection can cause it too; try the command again.
"Something went wrong running that command." The bot is running but hit an error. Look at the terminal where it runs: the error is printed there as Error in /commandname.
"Use this command inside a movie post that I created with /addmovie." You ran /watched or /unwatched outside a bot-made post. Open the post first.
"I couldn't find a movie called..." Check the spelling, or add the year.
A new movie has no IMDb or Rotten Tomatoes lines On purpose for movies that are not released yet (this saves OMDb's daily limit). The next refresh after release fills them in. If OMDb's daily limit is used up, ratings are missing until a later refresh.
You cannot use /addmovie Your role is not on the allowed list. An admin can change it with /setup.
/setup lists missing tags or permissions Add the tags in the forum's settings, or give the bot Create Posts, Send Messages in Posts, Attach Files and Manage Posts in the forum channel. Then run /setup again.
npm start says "Missing DISCORD_TOKEN" The .env file is missing or empty in the bot's folder. See Part 4.

Part 4: Keys and safety

The .env file in the bot's folder holds five values. Never share it, post it, or commit it to git.

NameWhat it is
DISCORD_TOKENThe bot's password (Discord Developer Portal → your app → Bot). If it ever leaks, reset it there right away.
CLIENT_IDThe app's ID (Developer Portal → General Information).
GUILD_IDYour server's ID. It tells npm run deploy which server gets the commands.
TMDB_API_KEYFree key from themoviedb.org (Settings → API). Used for movie details, posters and suggestions.
OMDB_API_KEYFree key from omdbapi.com. Used for IMDb and Rotten Tomatoes ratings (1,000 requests a day).
